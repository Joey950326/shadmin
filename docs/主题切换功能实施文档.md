# 主题切换功能实施文档

本文面向一个全新的 React + TypeScript 前端项目，提供一套可以直接执行的主题切换实施方案。完成后，项目将支持：

- 亮色、暗色和跟随系统三种主题模式；
- 浏览器系统主题变化监听；
- 主题模式刷新后持久化；
- 多套预设主题色；
- 灰色模式和色弱辅助模式；
- CSS 变量驱动的统一配色；
- Tailwind 语义化颜色 class；
- 支持 View Transition 的平滑切换动画，并兼容不支持该 API 的浏览器；
- 在设置面板和顶部按钮中复用同一套状态。

本文选择 Redux Toolkit + `redux-persist` 保存设置，使用 CSS 变量实现视觉切换。主题控件只修改状态，DOM 操作集中在 `ThemeProvider` 和主题工具函数中。

## 一、准备开发环境

### 步骤 1：创建 React + TypeScript 项目

```bash
pnpm create vite theme-demo --template react-ts
cd theme-demo
pnpm install
pnpm dev
```

浏览器打开 Vite 提示的地址，确认项目可以正常运行后停止开发服务器。

如果使用已有项目，确认项目具备以下基础条件：

- React 18 或更高版本；
- TypeScript；
- Vite 或其他支持 CSS 变量的构建工具；
- 浏览器端运行环境；
- 项目已经有统一的全局 CSS 入口。

### 步骤 2：安装依赖

安装状态管理、持久化和图标依赖：

```bash
pnpm add @reduxjs/toolkit react-redux redux-persist lucide-react
```

本方案使用 Tailwind CSS v4 的语义化颜色 class。如果项目还没有 Tailwind，安装：

```bash
pnpm add -D tailwindcss @tailwindcss/vite
```

不要同时安装 `next-themes` 并让它管理另一套主题状态。本方案只有 Redux 和 `ThemeProvider` 一个主题来源，避免两个主题系统互相覆盖。

### 步骤 3：配置 Tailwind v4

修改 `vite.config.ts`：


如果已有其他 Vite 插件，保留原插件，只新增 `tailwindcss()`。

确认 TypeScript 可以导入 React 和 JSON，并且项目的路径别名配置与后文示例一致。如果项目没有 `@/` 别名，将示例中的 `@/` 改成相对路径。

```ts
  value: ThemeMode;
  label: string;

  { value: "dark", label: "暗色" },
  { value: "system", label: "跟随系统" },
```

使用联合类型而不是普通 `string`，可以避免把不存在的主题色写入 Redux。

1. 将 `violet` 加入 `PRIMARY_COLORS`；
2. 在 CSS 中增加 `theme-violet` 的亮色和暗色变量；
3. 在设置界面增加颜色按钮；
4. 验证持久化、暗色和图表颜色。

## 四、创建 Redux 状态和持久化

### 步骤 6：创建 app slice

创建 `src/store/modules/app.ts`：

```ts
import type { PayloadAction } from "@reduxjs/toolkit";
import { createSlice } from "@reduxjs/toolkit";
import type { PrimaryColor, ThemeMode } from "@/features/theme/config";
import {
  DEFAULT_PRIMARY_COLOR,
  DEFAULT_THEME_MODE,
} from "@/features/theme/config";

export interface AppState {
  themeMode: ThemeMode;
  primaryColor: PrimaryColor;
  isDark: boolean;
  isGray: boolean;
  isColorWeak: boolean;
}

const initialState: AppState = {
  themeMode: DEFAULT_THEME_MODE,
  primaryColor: DEFAULT_PRIMARY_COLOR,
  isDark: false,
  isGray: false,
  isColorWeak: false,
};

const appSlice = createSlice({
  name: "app",
  initialState,
  reducers: {
    setThemeMode(state, action: PayloadAction<ThemeMode>) {
      state.themeMode = action.payload;
    },
    setPrimaryColor(state, action: PayloadAction<PrimaryColor>) {
      state.primaryColor = action.payload;
    },
    setIsDark(state, action: PayloadAction<boolean>) {
      state.isDark = action.payload;
    },
    setGrayMode(state, action: PayloadAction<boolean>) {
      state.isGray = action.payload;
    },
    setColorWeakMode(state, action: PayloadAction<boolean>) {
      state.isColorWeak = action.payload;
    },
  },
});

export const {
  setThemeMode,
  setPrimaryColor,
  setIsDark,
  setGrayMode,
  setColorWeakMode,
} = appSlice.actions;

export const selectThemeMode = (state: { app: AppState }) =>
  state.app.themeMode;
export const selectPrimaryColor = (state: { app: AppState }) =>
  state.app.primaryColor;
export const selectIsDark = (state: { app: AppState }) => state.app.isDark;
export const selectIsGray = (state: { app: AppState }) => state.app.isGray;
export const selectIsColorWeak = (state: { app: AppState }) =>
  state.app.isColorWeak;

export default appSlice.reducer;
```

这里将 `themeMode` 和 `isDark` 分开保存：

- `themeMode` 是用户意图，例如 `system`；
- `isDark` 是当前系统环境解析后的结果，例如系统当前为暗色时为 `true`。

如果业务没有其他地方需要读取 `isDark`，也可以只保存 `themeMode`，将 `isDark` 作为 ThemeProvider 内部的派生值。

### 步骤 7：创建 Redux store

创建 `src/store/index.ts`：

```ts
import { combineReducers, configureStore } from "@reduxjs/toolkit";
import {
  FLUSH,
  PAUSE,
  PERSIST,
  persistReducer,
  persistStore,
  PURGE,
  REGISTER,
  REHYDRATE,
} from "redux-persist";
import storage from "redux-persist/lib/storage";
import appReducer from "./modules/app";

const appPersistedReducer = persistReducer(
  {
    key: "app",
    storage,
    version: 1,
  },
  appReducer,
);

const rootReducer = combineReducers({
  app: appPersistedReducer,
});

export const store = configureStore({
  reducer: rootReducer,
  middleware: (getDefaultMiddleware) =>
    getDefaultMiddleware({
      serializableCheck: {
        ignoredActions: [FLUSH, REHYDRATE, PAUSE, PERSIST, PURGE, REGISTER],
      },
    }),
});

export const persistor = persistStore(store);

export type RootState = ReturnType<typeof store.getState>;
export type AppDispatch = typeof store.dispatch;
```

`persistReducer` 会将 `app` 状态保存到浏览器 localStorage。后续可以将用户信息、布局设置等其他 reducer 加入 `rootReducer`，但主题字段应继续归属于 app 设置。

### 步骤 8：创建类型化 Redux hooks

创建 `src/store/hooks.ts`：

```ts
import { useDispatch, useSelector } from "react-redux";

export const useAppDispatch = useDispatch.withTypes<AppDispatch>();
export const useAppSelector = useSelector.withTypes<RootState>();
```


### 步骤 9：创建 StoreProvider

创建 `src/features/store/StoreProvider.tsx`：

```tsx
import type { ReactNode } from "react";
import { Provider as ReduxProvider } from "react-redux";
import { PersistGate } from "redux-persist/integration/react";
import { persistor, store } from "@/store";

interface StoreProviderProps {
  children: ReactNode;
}

export function StoreProvider({ children }: StoreProviderProps) {
  return (
    <ReduxProvider store={store}>
      <PersistGate loading={<div>正在恢复设置...</div>} persistor={persistor}>
        {children}
      </PersistGate>
    </ReduxProvider>
  );
}
```

`PersistGate` 的作用是等待 localStorage 中的主题设置恢复后再渲染页面，减少页面先亮后暗的闪烁。

## 六、实现主题工具函数

### 步骤 12：创建 `shared.ts`

创建 `src/features/theme/shared.ts`：

```ts
import type { PrimaryColor } from "./config";

const THEME_COLOR_CLASSES: readonly string[] = [
  "theme-blue",
  "theme-orange",
  "theme-green",
  "theme-rose",
];

type ViewTransition = {
  ready: Promise<void>;
};

type TransitionDocument = Document & {
  startViewTransition?: (update: () => void) => ViewTransition;
};

export function changeThemeClassName(isDark: boolean) {
  document.documentElement.classList.toggle("dark", isDark);
}

export function getSystemThemeMode(): "light" | "dark" {
  return window.matchMedia("(prefers-color-scheme: dark)").matches
    ? "dark"
    : "light";
}

export function getSystemReduce(): boolean {
  return window.matchMedia("(prefers-reduced-motion: reduce)").matches;
}

export function isClassNameDark(): boolean {
  return document.documentElement.classList.contains("dark");
}

export function applyThemeMode(isDark: boolean) {
  if (isDark === isClassNameDark()) {
    return;
  }

  if (getSystemReduce()) {
    changeThemeClassName(isDark);
    return;
  }

  const transitionDocument = document as TransitionDocument;

  if (!transitionDocument.startViewTransition) {
    changeThemeClassName(isDark);
    return;
  }

  const transition = transitionDocument.startViewTransition(() => {
    changeThemeClassName(isDark);
  });

  const x = window.innerWidth;
  const y = 0;
  const endRadius = Math.hypot(window.innerWidth, window.innerHeight);

  void transition.ready
    .then(() => {
      const clipPath = [
        `circle(0px at ${x}px ${y}px)`,
        `circle(${endRadius}px at ${x}px ${y}px)`,
      ];

      document.documentElement.animate(
        {
          clipPath: isDark ? [...clipPath].reverse() : clipPath,
        },
        {
          duration: 300,
          easing: "ease-out",
        },
      );
    })
    .catch(() => {
      // 过渡失败时，主题 class 已经在回调中完成切换。
    });
}

export function changeColorClass(color: PrimaryColor) {
  const root = document.documentElement;

  root.classList.remove(...THEME_COLOR_CLASSES);
  root.classList.add(`theme-${color}`);
}
```

各函数职责如下：

- `changeThemeClassName`：只管理 `dark` class；
- `getSystemThemeMode`：读取操作系统亮暗色偏好；
- `getSystemReduce`：读取减少动画偏好；
- `isClassNameDark`：避免重复切换和重复动画；
- `applyThemeMode`：统一处理降级、View Transition 和主题 class；
- `changeColorClass`：先清理旧主题色，再增加新主题色。

主题动画的起点设置在右上角，扩散半径覆盖整个视口。不支持 View Transition 的浏览器会直接切换 class，不会影响功能。

## 七、创建 ThemeProvider

### 步骤 13：实现状态到 DOM 的同步

创建 `src/features/theme/ThemeProvider.tsx`：

```tsx
import { useEffect } from "react";
import { useAppDispatch, useAppSelector } from "@/store/hooks";
import {
  selectIsColorWeak,
  selectIsGray,
  selectPrimaryColor,
  selectThemeMode,
  setIsDark,
} from "@/store/modules/app";
import { applyThemeMode, changeColorClass, getSystemThemeMode } from "./shared";

interface ThemeProviderProps {
  children: React.ReactNode;
}

export function ThemeProvider({ children }: ThemeProviderProps) {
  const dispatch = useAppDispatch();
  const themeMode = useAppSelector(selectThemeMode);
  const primaryColor = useAppSelector(selectPrimaryColor);
  const isGray = useAppSelector(selectIsGray);
  const isColorWeak = useAppSelector(selectIsColorWeak);

  useEffect(() => {
    const media = window.matchMedia("(prefers-color-scheme: dark)");

    const applyMode = () => {
      const isDark =
        themeMode === "dark" || (themeMode === "system" && media.matches);

      dispatch(setIsDark(isDark));
      applyThemeMode(isDark);
    };

    applyMode();

    if (themeMode === "system") {
      media.addEventListener("change", applyMode);
    }

    return () => {
      media.removeEventListener("change", applyMode);
    };
  }, [dispatch, themeMode]);

  useEffect(() => {
    const filters: string[] = [];

    if (isGray) {
      filters.push("grayscale(100%)");
    }

    if (isColorWeak) {
      filters.push("invert(80%)");
    }

    const root = document.documentElement;
    root.style.filter = filters.length > 0 ? filters.join(" ") : "none";
    root.style.transition = "filter 0.45s ease";
  }, [isGray, isColorWeak]);

  useEffect(() => {
    changeColorClass(primaryColor);
  }, [primaryColor]);

  return children;
}
```

### 步骤 14：理解三个 effect

#### 主题模式 effect

它把用户选择解析为最终布尔值：

```text
light  → false
 dark  → true
system → matchMedia('(prefers-color-scheme: dark)').matches
```

当模式为 `system` 时注册媒体查询监听器；组件卸载或模式切换时移除监听器，避免事件监听泄漏。

#### 滤镜 effect

使用数组组合滤镜：

```css
filter: grayscale(100%) invert(80%);
```

这样开启色弱模式时不会覆盖灰色模式。两个开关都关闭时恢复为 `none`。

#### 主题色 effect

只依赖 `primaryColor`，修改根节点 `theme-*` class，不触发业务页面重新加载。

## 九、实现主题控件

### 步骤 17：实现循环切换按钮

创建 `src/components/theme/ThemeModeToggle.tsx`：

```tsx
import { Laptop, Moon, Sun } from "lucide-react";
import { useAppDispatch, useAppSelector } from "@/store/hooks";
import { selectThemeMode, setThemeMode } from "@/store/modules/app";
import type { ThemeMode } from "@/features/theme/config";

const modeSequence: ThemeMode[] = ["light", "dark", "system"];

export function ThemeModeToggle() {
  const dispatch = useAppDispatch();
  const themeMode = useAppSelector(selectThemeMode);

  const handleClick = () => {
    const currentIndex = modeSequence.indexOf(themeMode);
    const nextIndex = (currentIndex + 1) % modeSequence.length;
    dispatch(setThemeMode(modeSequence[nextIndex]));
  };

  return (
    <button
      type="button"
      aria-label="切换主题模式"
      title={`当前模式：${themeMode}`}
      className="inline-flex size-9 items-center justify-center rounded-md hover:bg-accent"
      onClick={handleClick}
    >
      {themeMode === "light" && <Sun className="size-4" />}
      {themeMode === "dark" && <Moon className="size-4" />}
      {themeMode === "system" && <Laptop className="size-4" />}
    </button>
  );
}
```

该组件直接使用 Redux 作为唯一数据源，不再额外保存本地 `useState`，因此设置面板修改模式后，顶部按钮图标也会同步更新。

点击顺序是：

```text
light → dark → system → light
```

### 步骤 18：实现三态模式选择

创建 `src/components/theme/ThemeModeGroup.tsx`。这里使用原生 radio，任何 UI 组件库都可以替换：

```tsx
import { useAppDispatch, useAppSelector } from "@/store/hooks";
import { selectThemeMode, setThemeMode } from "@/store/modules/app";
import { THEME_MODE_OPTIONS, type ThemeMode } from "@/features/theme/config";

export function ThemeModeGroup() {
  const dispatch = useAppDispatch();
  const themeMode = useAppSelector(selectThemeMode);

  const handleChange = (value: string) => {
    if (value === "light" || value === "dark" || value === "system") {
      dispatch(setThemeMode(value as ThemeMode));
    }
  };

  return (
    <fieldset>
      <legend className="mb-2 font-medium">主题模式</legend>
      <div className="flex gap-4">
        {THEME_MODE_OPTIONS.map((option) => (
          <label key={option.value} className="flex items-center gap-1.5">
            <input
              type="radio"
              name="theme-mode"
              value={option.value}
              checked={themeMode === option.value}
              onChange={(event) => handleChange(event.target.value)}
            />
            {option.label}
          </label>
        ))}
      </div>
    </fieldset>
  );
}
```

处理值时必须校验，而不是无条件执行 `value as ThemeMode`。某些单选组件允许取消当前值，可能传入空字符串。

## 十、在业务组件中使用主题颜色

### 步骤 22：统一使用语义化 class

推荐写法：


避免把业务组件写成固定白色或黑色：


## 十一、适配图表、Toast 和第三方组件

### 步骤 24：图表使用主题 CSS 变量

图表颜色不应只写死为某个十六进制值。可以为图表配置主题颜色：

```ts
const chartThemes = {
  light: {
    series: "var(--color-chart-1)",
  },
  dark: {
    series: "var(--color-chart-1)",
  },
};
```

如果图表库需要生成 CSS，可以使用：

```ts
const THEMES = {
  light: "",
  dark: ".dark",
} as const;
```

并为 `<html class="dark">` 和普通 `<html>` 生成对应的 CSS 规则。主题色变化时，应确认图表是否会重新读取 CSS 变量；不会自动更新的库需要销毁后重新配置。

### 步骤 25：Toast 使用同一个主题来源

不要再引入第二个主题 Provider。Toast 组件应读取 Redux 中的模式，或者直接依赖页面的 CSS 变量：

```tsx
import { useAppSelector } from "@/store/hooks";
import { selectThemeMode } from "@/store/modules/app";

export function AppToast() {
  const themeMode = useAppSelector(selectThemeMode);

  return <Toaster theme={themeMode} />;
}
```

如果 Toast 组件只使用 `var(--popover)`、`var(--popover-foreground)`、`var(--border)`，暗色和主题色切换后通常会自动生效。

### 步骤 26：检查 Portal 和全局节点

Dialog、Popover、Tooltip 和 Toast 往往通过 Portal 挂载到 `body`。由于 `dark` 和 `theme-*` 类挂在 `<html>` 上，它们仍然是后代节点，可以继承 CSS 变量和 `dark:` 规则。

如果第三方组件创建了独立 iframe 或 shadow root，则无法自动继承，需要通过组件 API 或额外 CSS 注入主题。

## 十二、避免首屏闪烁

### 步骤 27：理解闪烁原因

Redux Persist 的恢复和 React 的 `useEffect` 都发生在页面初始 HTML 加载之后，可能出现：

```text
初始 HTML 使用亮色
    ↓
React 挂载
    ↓
Redux 恢复为暗色
    ↓
ThemeProvider 添加 dark
```

页面可能短暂显示亮色，再切换为暗色。

### 步骤 28：加入首屏初始化脚本（可选）

如果项目对首屏闪烁敏感，可以在 `index.html` 的 `<head>` 中加入脚本，在 React 加载前设置 `html.dark`：

```html
<script>
  (() => {
    try {
      const persisted = localStorage.getItem("persist:app");
      const app = persisted ? JSON.parse(persisted) : null;
      const themeMode = app?.themeMode ? JSON.parse(app.themeMode) : "system";
      const systemDark = window.matchMedia(
        "(prefers-color-scheme: dark)",
      ).matches;
      const isDark =
        themeMode === "dark" || (themeMode === "system" && systemDark);

      document.documentElement.classList.toggle("dark", isDark);
    } catch {
      // 读取失败时使用 CSS 默认亮色。
    }
  })();
</script>
```

注意：`redux-persist` 保存的数据是嵌套 JSON，具体字段结构可能因 persist 配置而不同。上线前必须在浏览器中查看真实的 localStorage 值，并调整脚本读取路径。脚本只负责初始暗色 class，真正的状态同步仍由 `ThemeProvider` 负责。

## 十四、常见问题排查

### 1. 点击按钮后只有图标变化，页面颜色不变

按顺序检查：

1. `ThemeProvider` 是否包住页面内容；
2. `ThemeProvider` 是否在 Redux Provider 内部；
3. `document.documentElement.classList.contains('dark')` 是否随切换变化；
4. CSS 是否定义了 `.dark` 变量；
5. 组件是否仍使用 `bg-white`、`text-black` 等固定颜色；
6. Tailwind 是否加载了全局 CSS。

### 2. 主题色没有生效

检查：

- `primaryColor` 的值是否与 CSS 类名完全一致；
- `changeColorClass` 是否移除了旧类并添加了新类；
- CSS 是否使用 `:root.theme-blue` 而不是 `.theme-blue :root`；
- 暗色主题是否写成 `.dark.theme-blue`；
- 组件是否使用 `bg-primary` 等变量；
- 新颜色是否加入了清理数组。

### 3. 刷新后设置丢失

检查：

- 是否使用了 `persistReducer`；
- `appPersistedReducer` 是否注册到 root reducer；
- 应用是否包在 `PersistGate` 中；
- localStorage 是否被浏览器隐私策略禁用；
- 是否修改了 persist key 或 version；
- 是否在启动时重新创建了 store。

### 4. 设置面板和顶部按钮显示不同模式

不要让不同组件各自维护 `useState`。所有控件都应通过 `selectThemeMode` 读取 Redux，并只 dispatch `setThemeMode`。

### 5. 系统模式切换后页面不更新

确认 `ThemeProvider` 在 `themeMode === 'system'` 时注册了 `matchMedia` 的 `change` 监听，并在清理函数中移除了监听。

### 6. 浏览器不支持主题动画时报错

确认在调用 `startViewTransition` 前进行了能力检测：

```ts
if (!transitionDocument.startViewTransition) {
  changeThemeClassName(isDark);
  return;
}
```

主题功能不能依赖动画 API，动画只是一种增强效果。

### 7. 灰色模式关闭后仍然是灰色

检查是否将 `root.style.filter` 恢复为 `none`，并确认没有其他 CSS class 或父元素继续设置滤镜。

### 8. 色弱模式影响了二维码、图片或 Toast

因为滤镜设置在 `html` 上，整个页面都会受到影响。可以改为只对应用内容容器设置 filter，或为不应反转的内容使用独立容器并重新评估可访问性设计。

### 9. 主题变量在组件中没有提示

确认 Tailwind v4 的 `@theme inline` 中声明了对应变量，并重新启动 Vite。新增变量后，Tailwind 可能需要重新扫描 CSS 才能生成工具类。
